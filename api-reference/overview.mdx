---
title: "Endpoints overview"
description: "Every HTTP endpoint gligabao exposes."
---

All endpoints require `user_id` (in the JSON body, or the query string for `GET`/`DELETE`).

| Endpoint | Purpose | Docs |
| --- | --- | --- |
| `POST /v1/gb/remember` | Extract a temporal knowledge graph from text and store it; or, with `image`, read an image and store the extraction | [Remember](/api-reference/remember), [Artifacts](/concepts/artifacts), [Temporal facts](/concepts/temporal), [Images](/guides/images), [Chunking](/guides/chunking), [Web search](/guides/web-search), [Geo](/guides/geo), [Pipeline](/embedding/pipeline) |
| `POST /v1/gb/timeseries`, `GET /v1/gb/timeseries`, `GET /v1/gb/timeseries/{id}` | Store timeseries and anchor them to artifacts, entities and facts; list and read them. A `remember` request can also supply them, fetch them from the providers, or derive `series_observation` artifacts from them (`timeseries`) | [Timeseries](/api-reference/timeseries) |
| `POST /v1/gb/query` | Answer a question from the graph, with evidence | [Query](/api-reference/query), [Pipeline](/embedding/pipeline) |
| `POST /v1/gb/datasets`, `GET /v1/gb/datasets?user_id=`, `DELETE /v1/gb/datasets/{name}?user_id=` | Create, list and (soft) delete datasets | [Datasets](/concepts/datasets) |
| `GET /v1/gb/datasets/{name}/graph?user_id=` | Export a dataset's whole graph as JSON | [Graph export](/api-reference/graph) |
| `POST /v1/gb/ontologies`, `PUT /v1/gb/ontologies/{name}` | Load an OWL ontology (RDF/XML), or update the one stored under a name (merge or replace) | [Ontologies](/api-reference/ontologies) |
| `POST /v1/gb/research`, `GET /v1/gb/research`, `GET /v1/gb/research/{id}` | Start a deep-research agent on a topic (it searches the web, reads pages and works with your knowledge base with `remember`/`query` in the background, and ends with a report), list the agents (the active ones only, if asked), and read one with the states it went through; also `research_start`, `research_list` and `research_get` over MCP and `gligabao research` | [Research agents](/guides/research), [The deep-research agent](/guides/deep-research-agent), [Sub-agents and messages](/guides/subagents) |
| `/v1/gb/mcp` | [MCP](https://modelcontextprotocol.io) server (streamable HTTP) with `remember` and `query` (and the three research tools) as tools; off by default (`mcp = true` / `serve --mcp`), no authentication | [MCP](/guides/mcp) |
| `GET /health` | Health check | |
| `GET /version` | Version (and git commit) of the running binary | [Versioning](/operations/versioning) |

With [eval mode](/getting-started/configuration#eval-mode) enabled, `POST /v1/gb/eval/remember` and `POST /v1/gb/eval/query` are also registered.
