---
title: "Embedding in Go programs"
description: "Use gligabao as a Go library through the root package."
---

gligabao is also a Go library. All server code is under `internal/` (not importable); the public API is the root package `github.com/deepblue-phoenix/gligabao`, which the CLI (`cmd/gligabao`, `internal/cli`) itself uses, so embedded and standalone behave the same.

```go
import "github.com/deepblue-phoenix/gligabao"

cfg, err := gligabao.LoadConfig("gligabao.toml") // or gligabao.DefaultConfig()
if err != nil { /* ... */ }
err = gligabao.Serve(ctx, cfg, gligabao.ServeOptions{DBPath: "data/gligabao.db"})
```

## API

<AccordionGroup>
  <Accordion title="Config / Price">
    The configuration described in [Configuration](/getting-started/configuration). `DefaultConfig()` takes API keys from the environment, and fields can be set in code instead of a TOML file.
  </Accordion>
  <Accordion title="ServeOptions">
    `DBPath` (default `bin/gligabao.db`), `VectorDir` (the chromem directory; default `<name>.vectors` next to `DBPath`), `ImageDir` (image files; default `<name>.images` next to `DBPath`) and `TrainingDatasetDir` (the JSONL training datasets uploaded through the server or the admin UI; default `<name>.training_datasets` next to `DBPath`), the equivalents of `serve --db` / `--vector-dir` / `--image-dir` / `--training-dataset-dir`.
  </Accordion>
  <Accordion title="TimeseriesProviders">
    The [timeseries providers](/api-reference/timeseries#providers) `remember` can fetch from. Each is a `gligabao.TimeseriesProvider{Name, Description, QueryFormat, Fetch}`: `Description` says in natural language when the provider applies (an LLM reads it), `Fetch` is your callback that returns the series.
  </Accordion>
  <Accordion title="Hooks">
    Callbacks gligabao invokes, today the system-event hook (called after every `remember`, `recall` and timeseries request, with counts and timings). See [Hooks](/embedding/hooks).
  </Accordion>
  <Accordion title="Serve(ctx, cfg, opts)">
    Blocks until `ctx` is cancelled or SIGINT/SIGTERM arrives, then shuts down gracefully. A nil `cfg` means `DefaultConfig()`.
  </Accordion>
</AccordionGroup>

<Note>
  gligabao needs no CGO, so the embedding program can be built with `CGO_ENABLED=0`. A working example with a cobra `serve` command is in the sibling `gligabao_int` project, which uses `replace github.com/deepblue-phoenix/gligabao => ../gligabao` during local development. Programs can pass their own version in `ServeOptions.App`, and get `gligabao.Version()`.
</Note>
