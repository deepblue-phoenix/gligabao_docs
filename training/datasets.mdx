`side_car/ai_train/api/models.py`, `side_car/ai_train/ai_train_core/prompt_format.py`, `internal/sidecar/training_datasets.go`, `side_car/ai_train/finetune_data/`

A training dataset is a `.jsonl` file on the sidecar's data volume (`/data`). It is separate from a memory [dataset](/concepts/datasets), which is a container of artifacts, entities and edges in the database.

## Format

Each line is one training example:

| Key | Meaning |
| --- | --- |
| `instruction` | The task or user query, e.g. "Find news about NVIDIA and buy 10 shares". |
| `input` | Extra context. Often an empty string. |
| `output` | The expected multi-step answer, including tool usage. |

```json
{"instruction": "Check recent news about NVIDIA and buy 10 shares if it's positive", "input": "", "output": "I'll research NVIDIA news... [tool calls and reasoning]"}
```

Training turns each line into a string with Gemma turn markers (`format_instruction` in `ai_train_core/prompt_format.py`; inference uses the same format):

```
<start_of_turn>user
{instruction}

{input}<end_of_turn>
<start_of_turn>model
{output}<end_of_turn>
```

Without an `input` the blank line and `{input}` are left out. `load_training_dataset()` (`training_common.py`) reads the file, maps each entry through the formatter into a `text` field, builds a Hugging Face `Dataset` and hands it to the `SFTTrainer` with `dataset_text_field="text"`.

The bundled dataset (`finetune_data/`, 325 tool-calling examples on news and finance) is generated by `finetune_data/generate_dataset.py`. `modal run app.py --action validate` checks the remote dataset.

## `TrainingDataset`

`TrainingDataset` (pydantic, `api/models.py`; `sidecar.TrainingDataset` in Go) describes a dataset file:

| Field | Meaning |
| --- | --- |
| `filename` | The file name. Required. |
| `content` | Base64, or plain jsonl. Sent by the upload only; it is **never returned**. |
| `size_bytes` | Size of the file. |
| `uploaded_at` | When it was uploaded (from the metadata the upload leaves). |
| `modified_at` | The file's modification time. |

Timestamps are timezone-aware UTC, so the Go client can parse them.

## Uploading and listing

| Endpoint | Behaviour |
| --- | --- |
| `POST /datasets/upload` | Body `{filename, content}`; `content` is decoded as base64 if it is valid base64, otherwise taken as a plain utf-8 jsonl string. `400` if the filename or content is missing, or the filename is not a plain `*.jsonl` name (no path, no leading dot). Answers `{status, message, size_bytes}`. |
| `GET /datasets/list` | The `.jsonl` files on the data volume as `TrainingDataset` objects. |

The upload stores the bytes as `/data/<filename>` (an upload with the same name replaces that file) and keeps the given `filename` and the upload time in a metadata file (`/data/.metadata.json`). The list reports that `uploaded_at` for the file the metadata names, that is, the most recent upload. Several datasets can therefore live side by side.

## Choosing the dataset of a job

A job names its dataset by file name, in the `dataset` field of `POST /training/job_start` (and of the [admin endpoint](/training/jobs#starting-a-job-the-admin-endpoint) that calls it): the file must be a `*.jsonl` in `/data`, else the sidecar answers `400`. Without a `dataset` the job trains on the default dataset, `/data/gemma4_tool_calling_news_finance_v1.jsonl` (what `modal run app.py --action sync` writes). The **training** view of the admin UI fills its dataset picker from `GET /v1/gb/admin/api/training/datasets`, which returns the sidecar's list (`{"datasets": [...]}`; `502` if the sidecar fails, `503` if the sidecar is not active).

`modal run app.py --action sync` is the CLI way: it uploads the local `finetune_data` file as the default dataset, but only if it is newer than the remote one. `--action train` does it first.

## Go client

```go
resp, err := c.UploadTrainingDataset(ctx, "data.jsonl", jsonlBytes)  // POST /datasets/upload
sets, err := c.ListTrainingDatasets(ctx)                             // GET /datasets/list
```

`UploadTrainingDataset` base64-encodes the content and refuses an empty filename or content. `ListTrainingDatasets` returns `[]sidecar.TrainingDataset`; `SizeBytes`, `UploadedAt` and `ModifiedAt` are pointers, nil when the sidecar does not know them. The Go server exposes the list to the admin UI (above); there is no admin endpoint to upload a dataset.
